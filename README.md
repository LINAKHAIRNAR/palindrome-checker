# Palindrome Checker

A simple palindrome checker built using HTML, CSS, and JavaScript.

## Features
- Check if text or number is palindrome
- Interactive result display
- Input focus effects
- Responsive centered UI

## Technologies Used
- HTML
- CSS
- JavaScript

## What I Learned

- Functions
- Loops
- String reversal logic
- Conditional statements
